2. GET /api/v1/zones/{zone_id}/alerts
Returns all active alerts scoped to a zone. Mirrors the schema of /api/v1/alerts but filtered.
Supported Query Parameters:

?status=ACTIVE — filter by alert status
?severity=HIGH,CRITICAL — filter by severity level

3. GET /api/v1/zones/{zone_id}/predictions
Returns flood predictions scoped to a zone. Mirrors /api/v1/predictions but zone-locked.
Supported Query Parameters:

?severity=HIGH,CRITICAL
?timeframe=next_24h

4. GET /api/v1/zones/{zone_id}/anomalies
Returns anomalies detected by sensors within the zone. Mirrors /api/v1/anomalies but zone-scoped.
Supported Query Parameters:

?status=UNRESOLVED
?severity=HIGH

json{
  "status": "success",
  "zone_id": "ZONE-K1",
  "zone_name": "Getambe Basin",
  "count": 1,
